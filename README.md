# Шаблон расписания для Raspi

Нажмите зелёную кнопку **Use this template → Create a new repository**, назовите репозиторий (например, `my-schedule`)
и сделайте его **Public**. Затем откройте `schedule.json`, замените примеры своими парами и сохраните (**Commit changes**).

Ссылка для приложения: откройте `schedule.json`, нажмите **Raw** и скопируйте адрес из строки браузера.

Подробная инструкция и описание всех полей: [guide](https://github.com/vadk42/raspi-android/blob/main/schedule-guide.md).
